# 视频风格蒸馏专家

把"某位博主的视频感觉"拆解成结构化参数，再用这些参数生成同款风格的新视频。

## 0. 五条核心原则

| #      | 原则                                                                 | 展开        |
| ------ | ------------------------------------------------------------------ | --------- |
| **R1** | **先素材、后蒸馏、再生成**:素材不足不硬拆；蒸馏完成前不写分镜；分镜锁定后才出视频。三步顺序不可乱 | §1        |
| **R2** | **风格即参数,不是感觉**:所有"感觉"都要落到具体参数(配色 Hex/BPM/单镜时长/字幕位置),不留"高级感"这类空词 | §3        |
| **R3** | **七维全覆盖**:视觉基因/叙事结构/音频风格/字幕风格/内容公式/节奏时长/人格气质,缺一维就会"像但不对" | §3        |
| **R4** | **风格档案是唯一真源**:生成阶段只消费 style-profile.md,不回看原始素材分析过程;改风格只改档案 | §4、§5     |
| **R5** | **生成与出脚本双模式**:用户可选择"直接调用 GenerateVideo 出片"或"只出分镜+prompt 自行生成",技能都要支持 | §5        |

***

## 1. 工作流总览

```
① 素材收集 → ② 风格分析(七维拆解) → ③ 风格蒸馏(产出 style-profile.md) → ④ 风格应用(分镜+prompt+视频)
博主视频素材    逐维打分+写证据         结构化风格档案              生成同款新视频
```

### 1.1 三步不可乱(R1)

| 阶段 | 输入                | 输出                          | 通过标准                    |
| -- | ----------------- | --------------------------- | ----------------------- |
| ①  | 博主主页链接/视频文件/截图 | 原始素材清单(文本+视觉补充)         | 至少覆盖 5 条视频的可分析信息        |
| ②  | 原始素材清单            | 七维分析草稿(每维有证据)            | 每维至少 2 条来自素材的具体证据     |
| ③  | 七维分析草稿            | `style-profile.md`(风格档案)   | 七维参数全部填实,无空项/无"待定"    |
| ④  | style-profile.md  | 分镜脚本.md + 视频prompt + (可选)视频 | 分镜每列都引用了档案中的具体参数    |

> **阶段门禁**:上一阶段未通过标准,不进入下一阶段。素材不足时主动向用户索要更多视频链接/截图/描述。

***

## 2. 素材收集(①)

### 2.1 抖音素材获取

博主视频的风格信息藏在两个地方:**文本层**(标题/文案/评论)和**视觉层**(画面/剪辑/声音)。

**文本层获取**(通过浏览器访问博主主页):

1. 用浏览器打开博主抖音主页,记录:
   - 主页简介(人设定位)
   - 最近 10-20 条视频的标题/文案
   - 高赞视频的 Top 评论(用户感知到的风格点)
2. 若需要单条视频详情,进入视频页记录文案、话题标签、置顶评论。

**视觉层获取**(文本层无法覆盖画面):

- 优先方案:让用户提供 3-5 条代表性视频的**截图**(每镜 1-2 张,覆盖开头/中段/结尾)或**视频文件**。
- 备选方案:让用户用文字描述画面(配色/景别/运镜/人物/场景),按 §3 的七维逐项引导提问。
- 若用户无法提供视觉素材,在 style-profile 的视觉维度标注"基于文本推断",并在生成时降低视觉还原度预期。

### 2.2 素材清单模板

收集完整理成一张表(写进对话或临时文件):

| 视频编号 | 标题/文案 | 时长 | 截图/文件 | 用户补充描述 |
| ------ | ------- | -- | ------- | -------- |
| V01    | …       | 15s | ✅/❌    | …        |
| V02    | …       | 30s | ✅/❌    | …        |

> 至少收集 5 条视频才能进入 §3 分析。少于 5 条时向用户索要更多。

***

## 3. 风格分析(②)——七维拆解

对每条素材逐维分析,最后汇总。每维必须给出**参数值**和**证据来源**(来自哪条视频/哪条评论)。

### 3.1 V1 视觉基因

画面的"第一眼感觉",由 4 个子维度构成:

| 子维度    | 要填的参数                                | 示例                          |
| ------ | ------------------------------------ | --------------------------- |
| 配色     | 主色(Hex)+ 辅色(Hex)+ 色调(冷/暖/中性)        | `#1a1a1a 黑 + #f5c518 金,暖色调`  |
| 光影     | 光源方向 + 色温(K) + 光比 + 光质               | `45°侧光,3200K,3:1,柔光`       |
| 画质风格  | 胶片/数码/手机直出/赛博朋克/复古/高饱和/低饱和……     | `胶片颗粒感,低饱和,暗角`           |
| 镜头语言  | 常用景别(特写/中景/全景占比)+ 常用运镜(推/拉/摇/移/固定) | `70%特写+25%中景,固定+缓推`      |

### 3.2 V2 叙事结构

视频怎么"讲故事":

| 子维度    | 要填的参数                                   | 示例                          |
| ------ | ---------------------------------------- | --------------------------- |
| 骨架类型  | 快剪罗列/剧情起承转合/ASMR 感官/测评对比/Vlog 流水/口播说教 | `快剪罗列型`                     |
| 钩子方式  | 痛点问句/悬念动作/价格锚点/反常识数据/感官特写/金句前置     | `痛点问句前置:"你是不是也…"`          |
| 结构占比  | 开头钩子 X% / 中段内容 Y% / 结尾 CTA Z%           | `20%钩子 / 60%内容 / 20% CTA`    |
| 转场方式  | 硬切/淡入淡出/划像/缩放/匹配剪辑/无转场               | `硬切为主,偶尔缩放转场`              |

### 3.3 V3 音频风格

| 子维度    | 要填的参数                                | 示例                          |
| ------ | ------------------------------------ | --------------------------- |
| 人声     | 性别+年龄段+语气(播音/达人/耳语/嘶吼)+ 语速(字/分钟) | `女声25-30,达人语气,220字/分钟`    |
| BGM    | 风格+乐器+BPM+有无歌词                       | `轻快流行,木吉他,110BPM,无歌词`     |
| 环境音    | 常用环境音词(2-3个)+ 是否有音效点                  | `风声+键盘敲击,有按键音效点`            |
| 音画关系  | 卡点(卖点踩鼓点)/ 随情绪起伏 / 环境音主导无 BGM      | `卖点字幕弹出踩鼓点`                 |

### 3.4 V4 字幕风格

| 子维度    | 要填的参数                          | 示例                     |
| ------ | ------------------------------ | ---------------------- |
| 字体     | 字体族(黑体/圆体/宋体/手写体/综艺体)       | `粗黑体`                  |
| 颜色     | 主色 + 描边色 + 强调色                  | `白字黑边,关键词黄色`           |
| 位置     | 钩子/卖点/CTA 各自固定位置               | `钩子上1/3,卖点正中,CTA下半`   |
| 动效     | 入场+停留+出场                        | `弹入放大+停留2s+缓淡出`        |
| 音效     | 关键字幕是否配音效+音效类型                | `数据字幕配"叮"音效`          |
| 覆盖率    | 全片字幕 / 极简字幕(≤2条)/ 无字幕         | `全片字幕,覆盖钩子+卖点+CTA`    |

### 3.5 V5 内容公式

| 子维度    | 要填的参数                                | 示例                          |
| ------ | ------------------------------------ | --------------------------- |
| 选题模式  | 测评/种草/教程/剧情/搞笑/知识科普/生活记录            | `产品测评+对比`                 |
| 开头公式  | 固定开头句式/动作                            | `"这个XX到底值不值?"`            |
| 结尾公式  | CTA 类型(关注/点赞/购买/评论互动)/ 固定 slogan   | `"关注我,下期测XX"`             |
| 话题标签  | 常用 hashtag 模式                         | `#测评 #好物分享`              |

### 3.6 V6 节奏与时长

| 子维度    | 要填的参数                  | 示例            |
| ------ | ---------------------- | ------------- |
| 平均时长  | 单条视频时长(秒)              | `15-30s`       |
| 单镜时长  | 平均每个镜头持续时间             | `1.5-2.5s`     |
| 节奏曲线  | 匀速/前快后慢/前慢后快/起伏       | `前快后慢,结尾放慢`  |
| 信息密度  | 每秒传达的信息量(高/中/低)         | `高,每秒1个卖点`   |

### 3.7 V7 人格气质

博主的"人设"和情绪基调:

| 子维度    | 要填的参数                           | 示例                     |
| ------ | ------------------------------- | ---------------------- |
| 人设定位  | 身份/角色标签(测评博主/闺蜜/专家/搞笑男/治愈系)     | `理性测评博主,像数码区朋友`       |
| 情绪基调  | 整体情绪(燃/暖/冷/飒/治愈/搞笑/专业)       | `专业理性,偶尔冷幽默`          |
| 口头禅/金句 | 高频出现的口头语或标志性句式                 | `"说实话""亲测"`            |
| 与观众关系 | 平视/仰视/俯视/陪伴感                   | `平视,像朋友推荐`            |

### 3.8 分析记录表

每维分析时用此表记录(证据必须可追溯):

| 维度 | 参数项 | 参数值 | 证据(来自视频 V0X 的…) |
| -- | --- | --- | ---------------- |
| V1 | 配色 | … | V01 封面+V03 中段画面 |
| V2 | 钩子 | … | V02/V04/V05 开头都是痛点问句 |

***

## 4. 风格蒸馏(③)——产出 style-profile.md

把 §3 的分析结果汇总成一份**结构化风格档案**。这是后续生成的唯一真源(R4)。

### 4.1 命名与位置

```
<博主昵称>_style-profile.md
```

放在工作目录下,生成阶段直接读取。

### 4.2 档案结构

使用 `references/style-profile-template.md` 模板,包含:

1. **博主基本信息**:昵称、平台、赛道、粉丝量级(可选)
2. **七维风格参数**:V1-V7 全部参数值(从 §3 汇总)
3. **风格一句话总结**:"用一句话概括这个博主的视频感觉"(用于生成时快速对齐)
4. **风格关键词云**:5-10 个关键词(用于 prompt 注入)
5. **典型分镜节奏**:一条代表性视频的镜次-时长-内容节奏(用于复用结构)
6. **禁区**:这个博主绝不会出现的元素(如"不用特效字幕""不露产品 Logo")

### 4.3 蒸馏校验

档案写完后自查:
- [ ] 七维 V1-V7 每维的所有子项都填了具体值,无"待定""高级感"
- [ ] 至少 70% 的参数值有证据来源标注
- [ ] "风格一句话总结"和"关键词云"与参数一致,不矛盾
- [ ] "禁区"至少列 2 条(每个博主都有不做的事)

未通过则回到 §3 补分析。

***

## 5. 风格应用(④)——生成同款新视频

基于 style-profile.md 生成新视频。支持两种模式(R5)。

### 5.1 模式选择

询问用户或根据上下文判定:

| 模式       | 产出                      | 适用场景                    |
| -------- | ----------------------- | ----------------------- |
| **直接生成** | 分镜脚本 + 视频 prompt + 调用 GenerateVideo 出片 | 用户要直接拿成品视频              |
| **仅出脚本**  | 分镜脚本 + 视频 prompt(不调用生成)     | 用户要拿去其他模型/工具自行生成        |

### 5.2 需求输入

生成前向用户确认(用合理默认补齐):

| 槽位  | 说明              | 默认               |
| --- | --------------- | ---------------- |
| 主题  | 新视频要讲什么(产品/话题/故事) | 必须问,无默认          |
| 目标  | 转化/种草/认知       | 默认"种草"           |
| 时长  | 目标时长(秒)         | 默认复用档案的平均时长      |
| 素材  | 是否有参考图/产品图     | 无则纯生成           |

### 5.3 分镜脚本生成

复用档案中的**叙事结构(V2)+ 节奏(V6)+ 典型分镜节奏**搭建骨架,用**视觉基因(V1)** 填画面,用**音频(V3)+ 字幕(V4)+ 内容公式(V5)** 填音轨和文字。

分镜表列规范(参考 `references/storyboard-template.md`):

| 列     | 填写要求                        |
| ----- | --------------------------- |
| 镜号    | S01-01 起                     |
| 时长    | 复用档案单镜时长区间                  |
| 景别视角  | 从 V1 镜头语言中选                   |
| 运镜    | 从 V1 镜头语言中选                   |
| 光影色彩  | 直接抄 V1 参数                    |
| 主体动作  | 按主题填写,动作风格匹配 V7 人设          |
| 道具环境  | 匹配 V1 画质风格,避免跳出风格            |
| 音频三层  | 人声抄 V3,BGM 抄 V3,环境音抄 V3       |
| 屏显字幕  | 完全按 V4 规范(字体/颜色/位置/动效)     |
| 视觉重点  | ★ 标记封面级画面,密度参考 V6 信息密度      |

> **关键**:每一列都要能追溯到 style-profile 中的某个参数。如果某列填不出,说明档案该维度缺失,回到 §4 补档案,不要凭感觉填。

### 5.4 视频 prompt 生成

按"七维骨架"组装 prompt(参考 ecom-video-generation 的方法):

```
[主体] + [详细动作] + [场景/环境] + [光线/色调] + [镜头运动] + [视觉风格/画质] + [约束条件]
```

**风格注入**:在 `[视觉风格/画质]` 和 `[约束条件]` 中注入 style-profile 的关键词和参数:

```
视觉风格: <V1画质风格>, <V1配色>, <V1光影>
约束条件: 保持<博主昵称>的风格特征——<风格关键词云>;禁区:<禁区列表>
```

多镜头写进同一条 prompt:`Shot 1: … Shot 2: …`(单段 ≤15s 时)。

### 5.5 调用 GenerateVideo(直接生成模式)

1. 组装好完整 prompt(含风格注入)
2. 确定参数:
   - `resolution`:默认 720p,用户要求高则更高
   - `ratio`:默认 `9:16`(抖音竖屏),按用户需求调整
   - `duration`:按 §5.2 时长,单段 ≤15s
3. 调用 `GenerateVideo` 工具,传入 prompt、时长、比例
4. 生成后告知用户文件路径,并提示"如需修改风格参数,编辑 style-profile 后重新生成"

> 时长 >15s 时按 ecom-video-generation 的分段策略拆段,段间用"同一参考图作主体锚点、后段以前段末帧作首帧、风格参数照抄档案"保持一致。

### 5.6 仅出脚本模式

只输出分镜脚本 `.md` 文件和视频 prompt 文本,不调用 GenerateVideo。提示用户可自行将 prompt 用于其他视频生成工具。

***

## 6. 交付物清单

一次完整的风格蒸馏+生成,交付:

| 文件                        | 阶段 | 说明                   |
| ------------------------- | -- | -------------------- |
| `<博主>_style-profile.md` | ③  | 风格档案,可复用、可迭代       |
| `<主题>_分镜_<版本>.md`     | ④  | 分镜脚本(含视频 prompt)   |
| `output.mp4`(直接生成模式)   | ④  | 生成的视频文件              |

> style-profile.md 是核心资产:换主题重新生成时,只需复用档案 + 提供新主题,无需重新分析博主。

***

## 7. 常见返工点

| 反模式                     | 违反原则 | 正确做法                     |
| ----------------------- | ---- | ------------------------ |
| 只看 1 条视频就下结论              | R1   | 至少 5 条,覆盖不同主题/时长          |
| 风格档案里写"高级感""有质感"        | R2   | 拆成具体参数:配色/光影/BPM/单镜时长   |
| 生成时跳过档案凭感觉写分镜           | R4   | 每列参数必须引用 style-profile   |
| 七维只填了视觉,没填音频/字幕/人设     | R3   | 七维全覆盖,缺哪维补哪维             |
| 用户说"模仿某博主"却不收集素材直接生成    | R1   | 先走完 ①②③ 再生成               |
